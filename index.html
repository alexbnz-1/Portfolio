UNIVERSITY TEAM PROJECT · 202501

ROBOTICS / INTEGRATED MECHATRONICS

Autonomous line-follower

Small robot. A lot of engineering.

An ENMT221 team project combining a custom chassis, electronics and bare-metal control to follow a line course at speed.

  • SolidWorks
  • KiCad
  • Bare-metal C
  • PID control
Inside the project+

The engineering challenge

Balance speed, traction and reliable line tracking when every mechanical, electrical and control decision affects the others.

The approach

The robot combines a PETG chassis, custom gearbox, dual-PCB electronics and an ATmega4808 controller. Wireless parameter tuning makes control iterations faster.

  • PID line tracking with anti-windup, feed-forward and lost-line recovery.
  • Separate infrared sensor and motor-control boards.
  • Custom plastisol tyres developed after testing different materials.

University team project · ENMT221, Mechatronics Design 1 · 2025. Mechanical, electrical and control development were iterated together.

UNIVERSITY PROJECT · 202502

MECHANICAL DESIGN / PROTOTYPING

Desktop CNC machine

A more accessible way to make.

A university project designing and building a compact desktop CNC machine for hobby and educational use.

  • CAD
  • 3D printing
  • G-code
  • Design iteration
Inside the project+

The engineering challenge

Improve gantry rigidity without losing the simplicity and accessibility of a compact desktop machine.

The approach

Early designs allowed the gantry to twist when motors moved out of sync. Successive mounting iterations led to a plate that wrapped around the cross member, increasing contact area and reducing twisting.

  • CAD development from the initial concept to the final assembly.
  • Iterative gantry and mounting design.
  • A physical prototype integrating motion control and fabrication.

Original CAD renders and a photograph of the built machine are shown here.

PERSONAL PROJECT · IN DEVELOPMENT03

ELECTRONICS / HARDWARE DESIGN

RoboDev

A single board. More room to build.

An open-source robotics carrier board design that brings motor drivers, sensor connections and wireless communication into one integrated platform.

  • KiCad
  • STM32
  • ESP32-C3
  • I²C / SPI / CAN
Inside the project+

The engineering challenge

Robotics prototypes can accumulate breakout boards and complicated wiring. RoboDev explores a single carrier board with a dedicated controller for real-time I/O and a separate wireless co-processor.

Design scope

  • DC motor, servo and stepper interfaces.
  • Isolated I²C expansion and CAN connectivity.
  • Hierarchical schematics and independent power rails.

In development. The public project documents a substantially complete schematic; PCB layout, fabrication and bring-up remain future milestones. Channel counts describe the design, not tested hardware.

EMBEDDED SYSTEMS / DEVELOPER TOOLS

OpenBrain

A reusable foundation for the next robot.

A Raspberry Pi 5 and ESP32 platform that separates application software from time-sensitive hardware control, with a Python API and desktop tooling.

  • Raspberry Pi 5
  • ESP32
  • Python
  • PlatformIO
Inside the project+

The engineering challenge

Keep application-level software flexible while giving hardware communication a clear, predictable interface.

The approach

The Pi handles applications and tooling; the ESP32 handles device communication and time-sensitive I/O. Capability discovery exposes only the interfaces a connected device reports.

  • Versioned serial protocol, heartbeat monitoring and explicit arming.
  • A hardware-free simulator for development and testing.
  • Python device APIs, a PyQt6 interface and Pi-owned firmware build/upload tools.

The connection and firmware workflow have been verified on the Pi and ESP32. Physical motor and sensor drivers remain the next integration step.

ENGINEERING SOFTWARE / STRUCTURAL ANALYSIS

Frame analysis toolkit

From a frame model to the forces within.

A Python toolkit and desktop interface for two-dimensional frame, beam and bar analysis using the direct-stiffness method.

  • Python
  • NumPy
  • PyQt6
  • Matplotlib
Inside the project+

The engineering challenge

Turn structural analysis into a workflow where geometry, loading and the calculation results can be inspected together.

The approach

The solver assembles element stiffness matrices, applies supports and loads, and calculates displacements, reactions and element forces. Shared application logic supports both desktop interfaces.

  • Interactive nodes, elements, supports and load editing.
  • Deflected-shape plotting and calculation reports.
  • Session files, undo, zoom/pan and a command palette in the Qt interface.

ENME302 project. The direct-stiffness solver and graphical interfaces share the same model and calculation engine.

UNIVERSITY TEAM PROJECT · 202507

CONTROL SYSTEMS / AUTOMATION

Elevator control system

Five floors. One coordinated control system.

A university team project implementing speed regulation, request scheduling and door interlocks for a five-floor elevator.

  • PLC
  • Structured Text
  • PI control
  • Scheduling
Inside the project+

The engineering challenge

Coordinate smooth travel, floor requests and door states in a single control sequence.

The approach

The system uses a PI speed controller and a directional scheduling algorithm to handle floor requests while reducing unnecessary reversals.

  • Speed-controller tuning across floor transitions.
  • A request scheduler implemented in Structured Text.
  • Door and motion interlocks, tested in simulation and scaled rigs.

University team project · 2025. The image shows the elevator simulator used to test control logic before working with scaled elevator rigs.
